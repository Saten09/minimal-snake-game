# Snake — Minimal Arcade
A mobile-friendly Snake game made with HTML, CSS and vanilla JavaScript.

Features: swipe controls, keyboard arrows, pause/resume/restart, three speeds, score, locally saved best score, responsive layout, PWA manifest and service worker.

## Deploy with GitHub Pages
1. Create a public GitHub repository.
2. Upload the contents of this folder (not the ZIP itself) to the repository root.
3. Open Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/(root)`, then Save.
5. Open the Pages URL when it appears.

## Add to Home Screen
- iPhone: open the Pages URL in Safari → Share → Add to Home Screen.
- Android: open the URL in Chrome → menu → Install app or Add to Home screen.

Best score is stored locally in the browser on each device.
